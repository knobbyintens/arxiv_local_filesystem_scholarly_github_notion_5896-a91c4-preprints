# HELIX-2: Scaling Sparse Routing to Million-Token Contexts

- Record: MRD-2025-0387
- Version: v1 (posted 2025-11-03)
- Authors: Mei Lin, Darius Okonkwo
- Topic: efficient long-context attention
- Review state: pending

## Abstract
HELIX-2 extends the sparse routing design of the original HELIX record to contexts of one million tokens. It reports strong needle-retrieval numbers but requires a new routing controller trained from scratch.
